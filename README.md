Eisenhower Matrix App



A CRUD app to organize tasks in order of importance based on 4 quadrants.


Link:
https://eisenhower-matrix-w38v.onrender.com

Built using:

HTML, CSS, JavaScript for the frontend
Flask, SQLite for the backend


Features:
1) The app is able to create tasks by inputting the required text and selecting the quadrant
2) Mark tasks as complete by using the checkbox
3) Delete tasks by clicking the delete button
4) Features data saving through different sessions

How to run:

1. open terminal and within the project root type "git clone github.com/blech0/eisenhower-matrix"
2. "install dependencies with pip install -r requirements.txt"
3. open the terminal  and type "python app.py"
4. copy the local ip
5. paste it in browser
